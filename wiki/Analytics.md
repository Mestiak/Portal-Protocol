# Analytics

Portal Protocol provides detailed analytics for your raid, strike, and fractal encounters.

## Accessing Analytics

Click the **Analytics** tab in the main navigation to view your statistics.

## Overview Dashboard

The main dashboard shows:

| Metric | Description |
|--------|-------------|
| Total Clears | Number of successful kills across all encounters |
| Total Logs | All uploads (kills + wipes) |
| Success Rate | Percentage of kills vs total attempts |
| CM Clears | Challenge Mode clears only |
| Average Duration | Mean kill time across all encounters |

## Encounter Breakdown

View statistics per encounter:

- **Clear Count**: Successful kills
- **Wipe Count**: Failed attempts
- **Success Rate**: Kill percentage
- **Fastest Kill**: Best time
- **Average Duration**: Mean time across all kills
- **Mode Split**: CM/QP/Normal distribution

Click any encounter row to expand detailed stats.

## Personal Records

Track your best performances:

- **Fastest Kill**: Quickest clear per boss
- **Lowest HP**: Best pull (closest to kill)
- **CM Best**: Fastest CM clear per encounter
- **Longest Fight**: Maximum duration recorded

Records update automatically as you upload new logs.

## Trends

Visualize your progression:

- **Weekly Activity**: Bar chart of clears per week
- **Success Rate Over Time**: Line graph showing improvement
- **Duration Trends**: See your times getting faster
- **Mode Distribution**: Pie chart of CM/QP/Normal splits

## Filtering

Narrow down your analytics:

- **Date Range**: Last 7 days, 30 days, 90 days, all time
- **Mode**: All, CM only, QP only, Normal only
- **Type**: Raids, strikes, fractals, all
- **Boss**: Specific encounter

## Exporting Data

Copy analytics summaries for sharing:

1. Set your desired filters
2. Click **Copy Summary**
3. Paste into Discord, forums, or spreadsheets

The summary includes all visible metrics in a formatted table.

## Data Sources

Analytics are calculated from:
- Local log database (all logs you've uploaded)
- EVTC enrichment data (HP, phases, squad)
- dps.report metadata (players, traits, stats)

All data is stored locally — no external API calls for analytics.
