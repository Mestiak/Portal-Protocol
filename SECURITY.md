We take security vulnerabilities seriously. If you discover one, please report it by:

- Opening a private discussion on GitHub
- Or contacting us through Discord
- Username: Mestiak

**What to include:**
- Description of the vulnerability
- Steps to reproduce
- Any potential impact

**Response timeline:**
- We acknowledge reports within 72 hours
- We aim to fix critical issues within a week

**What happens next:**
- If accepted: We fix it and credit you (if you want)
- If declined: We explain why
